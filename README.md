# Eternity Tweaks

### Windows Performance Utility

Eternity Tweaks is a lightweight Windows performance utility designed for gamers who want quick access to system optimization tools without navigating through Windows settings or manually applying complicated tweaks.

Built with a clean, focused interface and practical system controls.

## Overview

Eternity Tweaks brings commonly used Windows performance and maintenance controls into a single application.

Instead of manually searching through Windows settings, Task Manager, networking tools, and system utilities, Eternity Tweaks provides a centralized interface for managing them.

The application focuses on practical Windows functionality rather than exaggerated performance claims.

---

## Features

### Game Boost

Optimize supported games while they are running.

* Detect running games
* Apply high process priority
* Restore the previous process priority
* Designed for legitimate Windows performance optimization

### Windows Optimization

Access performance-related Windows controls from one interface.

* Performance power plans
* System optimization controls
* Gaming-related settings
* Reversible configuration where supported

### Background Processes

Quickly identify selected non-essential background applications and close them before launching a game.

The feature is intentionally limited to known user applications and does not terminate arbitrary Windows system processes.

### Network Tools

Built-in network utilities for troubleshooting and maintenance.

* Ping testing
* DNS cache flushing
* Basic connection diagnostics

Network tools provide maintenance and diagnostics; they cannot change the physical latency of your internet connection.

### System Cleaner

Remove unnecessary temporary files using a simple interface.

Designed to eliminate common temporary data without requiring users to manually browse Windows system folders.

### Restore

Optimization should not mean losing control of your previous configuration.

Eternity Tweaks is designed to restore settings where the application has modified and recorded their previous state.

## Installation

No configuration is required.

### 1. Download

Open the **Releases** section of this repository and download the latest:

**Eternity Tweaks Setup**

### 2. Install

Run the installer and follow the Windows setup wizard.

Choose your installation location and create shortcuts if desired.

### 3. Launch

Open **Eternity Tweaks** from the Desktop or Start Menu.

That's it.

## Design Principles

Eternity Tweaks is built around a simple principle:

> Give users useful Windows controls without unnecessary complexity.

The application avoids the typical "one-click 500 FPS boost" approach and instead focuses on actual Windows functionality.

No fake FPS counters.
No fabricated performance measurements.
No random registry modifications.
No cheat functionality.
No anti-cheat bypasses.

Just practical system controls in one interface.

## Disclaimer

Eternity Tweaks modifies Windows settings and processes in order to provide its optimization features.

Results may vary depending on hardware, drivers, Windows configuration, and the individual game.

Always review changes before applying advanced system modifications.

Eternity Tweaks does not provide cheats, exploits, anti-cheat bypasses, ban evasion, or other mechanisms intended to circumvent game security.
